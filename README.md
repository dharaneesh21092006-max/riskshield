# RiskShield

Evidence-first digital risk protection for social and app ecosystems.

## Live website

**[Open the published RiskShield website](https://dharaneesh21092006-max.github.io/riskshield/)**

## Included

- Responsive risk overview dashboard
- Social media and app-store monitoring findings
- Evidence-rich triage workflow with statuses and notes
- Brand profile with official asset exclusion
- Source health and unavailable-source handling
- Guided analyst demo
- Transparent detection architecture view

The prototype uses browser persistence for demo workspace state.
